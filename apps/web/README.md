# apps/web

React + Vite frontend for Apogee. It talks only to the API (`/api`, proxied to
`localhost:8000` in dev; run `make dev-api` from the repo root) and never defines
backend types by hand. They come from `src/lib/api/schema.gen.ts`, generated by
`make codegen`.

```sh
# from apps/web
pnpm install
pnpm dev      # http://localhost:5173
pnpm test     # vitest
pnpm build    # typecheck + production build
```

## Layout

| Path | Holds |
| --- | --- |
| `src/app/` | Router, shell, rail, status bar, section registry (`sections.ts`) |
| `src/sections/<id>/` | One folder per rail item; exports `Centre` and optionally `Pane` |
| `src/components/` | Shared widgets; `ui/` holds shadcn-style primitives |
| `src/lib/api/` | Generated API types plus a thin typed client (see its README) |
| `src/lib/units.ts` | The only place SI values become display units, and back |
| `src/stores/` | Zustand: mission draft (Immer + undo/redo), UI preferences (persisted) |

## Conventions

- **SI everywhere.** Stores and API payloads are SI. Convert with `lib/units.ts` at render time only.
- **One rhythm per section.** The right pane edits inputs, one primary action runs it, the centre shows the result, and the status bar tracks the job.
- **Adding a section:** create `src/sections/<id>/index.tsx` exporting `Centre` (and `Pane`), then add one entry to `SECTIONS` in `src/app/sections.ts`. The route, rail item, lazy loading and persisted pane layout come from that entry.
- **Theme.** Dark by default; light is a high-contrast sunlight mode. Colours are CSS tokens in `src/index.css`, named the shadcn way (`primary`, `foreground`, `muted-foreground`, `border`, …), so components from shadcn registries theme correctly as-is. `surface`/`surface-2` and green/amber/red (`go`/`caution`/`nogo`, reserved for status) are Apogee additions. `dark:` follows the app's `data-theme`, not the OS.
- **Maps** use [mapcn](https://mapcn.dev) (`src/components/ui/map.tsx`, added with `pnpm dlx shadcn@latest add @mapcn/map`). It's owned code with two local patches marked `apogee:`: the MapLibre worker is bundled rather than fetched from unpkg, and basemaps come from `src/lib/mapStyles.ts` (PMTiles from the stack, or blank) rather than the CARTO CDN. Re-apply both if you update it from the registry.
- **Offline.** No runtime CDN: fonts are bundled via `@fontsource`, the map worker is bundled, and basemap tiles come from a PMTiles file served by the stack (`VITE_MAP_PMTILES`).
- **Motion.** `MotionConfig reducedMotion="user"` wraps the app. Nothing a user must read quickly in the field is animated.
